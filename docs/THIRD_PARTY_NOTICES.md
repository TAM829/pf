# 使用素材・クレジット

## 亀のロゴ

- 提供元：DesignEvo（https://www.designevo.com/）。
- 使用元：ユーザー提供の `logo_kame01.zip` 内の `logo/high-res/logo-transparent.png`。
- Web用処理：透過領域の余白を整理、サイトの青に色調を統一、縮小とPNG最適化。輪郭の描き直しは行っていません。
- 対象：`assets/turtle.png`、同じ亀を使用したファビコン、Apple touch icon、OGP画像。
- 公開クレジット：Logo created with DesignEvo。
- 利用条件：https://www.designevo.com/terms.html

亀をサイト独自の著作物とする表示や、独占権を取得したとする表示は行いません。この文書は第三者素材に新たな利用許諾を付与するものではありません。

## その他の素材

- `assets/network.svg`、`assets/circuits.svg` とUIアイコン：本サイト用に作成した固定SVG。
- フォント：閲覧端末のシステムフォントを利用。フォントファイルは同梱・配信していません。
- 外部の実行用ライブラリ・CDN：使用していません。

素材を追加・差し替えた場合は、実際の提供元と必要なクレジットを更新してください。
